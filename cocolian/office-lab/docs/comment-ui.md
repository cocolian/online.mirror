# Writer 批注界面

Writer 批注与修订卡片统一采用简洁的页边样式：作者、正文、左侧强调线，移除卡片阴影和头像，保留折叠讨论的计数。默认只显示作者和内容。时间、解决对勾和“⋮”只在悬浮或键盘聚焦时显示；修订卡片显示接受“✓”、拒绝“×”及“⋮”，编辑修订批注放入下拉菜单。它们保留布局空间，因此显示时不会移动后续批注。触屏没有悬浮，操作保持可见；菜单展开后也持续显示当前卡片的操作。

对勾复用原生解决/重新打开批注命令；修改、回复、删除、线程操作及导航仍在原生菜单中。修订的接受和拒绝继续按原生修订 ID 执行，点击操作不会继续触发卡片选择；AI 审阅关联保持原流程。按钮遵循当前编辑权限、作者权限和宿主的 Hide_Command/HideChangeTrackingControls 设置，解决状态变化后同步更新无障碍名称与按下状态。菜单支持 Enter/Space，键盘跳转到批注时聚焦菜单。表格及演示文稿保留原有视觉样式。

## 验证

在环境中安全提供 `LAB_KEY`，并安装 Playwright 与 Chrome 后运行：

```sh
python cocolian/office-lab/scripts/verify-comment-style.py --base https://office.cocolian.cn --output comment-style-validation
```

脚本只新建合成测试文档，验证默认/悬浮显示、卡片高度不变、菜单展开状态、修改与回复、键盘解决和重新打开、宿主命令隐藏、只读切换、删除回复、WOPI 保存和刷新。输出截图与结果，不打印登录密钥。候选代码可用 `--candidate` 指向包含 `candidate-methods.json` 和 `online/browser/css/cool.css` 的临时构建目录；正式验收不替换浏览器资源。

## 初始缩放与已有浏览器缓存

Writer 首次打开按实际文档画布（扣除大纲/会话和属性栏）适配，并为已有批注留出完整宽度和间距，自动适配最多 100%。手机不预留桌面批注栏，手动缩放仍可超过 100%。`test_writer_zoom.cjs` 覆盖已有批注、宽屏上限、窄屏、移动端及手动缩放保持。

增量构建目录是源码导出，不含 `.git`。每次编辑器构建必须将真实源码提交写入 `dist_git_hash`，重新生成 `config_version.h` 并验证；否则服务端继续把变化后的脚本和样式放在相同地址下缓存 128 天。发布后检查两个编辑器入口均使用本次版本号。验收应同时检查新会话和已缓存旧资源的现有页面，不能仅凭无缓存会话的结果判定普通刷新有效。

## 批注与修订定位

Writer 右侧的批注和修订按文档顺序排列。点击卡片只切换选中状态和展开其内容，不以选中锚点重新排列整列，也不单独把选中卡片挪到其他卡片上。滚动以布局完成后的卡片位置为准；超出文档视口的部分被裁剪，不能覆盖工具栏或拦截其点击。

AI 审阅定期读取原生修订表时，相同数据不重建卡片。数据变化时按 ID 恢复原来的选择，修订还需匹配作者、时间、类型和描述，避免原生索引复用后选中另一处修订。编辑中的卡片不被后台刷新销毁。回复导航保留被点击的回复作为展开目标。

回归覆盖同锚点的普通批注与多条修订、连续切换、周期刷新、回复目标、编辑保护及工具栏边界。运行 `node --test cocolian/office-lab/scripts/devops/test_comment_navigation.cjs`；发布构建在 TypeScript/ESLint 编译通过后执行此测试。
