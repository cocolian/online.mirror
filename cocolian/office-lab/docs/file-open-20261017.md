# 打开文件与知识库

保存图标左侧的文件夹按钮打开选择窗口，提供知识库、本地上传两种来源。文件在新标签页打开，原文档继续保留；上传限制 1 GB（1024 MB），支持 docx/doc/odt/rtf/txt、xlsx/xls/ods、pptx/ppt/odp。

## 目录与持久化

- 容器目录：`/data/knowledge-base`，由 `KNOWLEDGE_DIR` 显式指定。
- 沿用 `office-lab/wopi-data` 的 2 GiB 持久卷，不新增数据库。
- cocoserver 上的目录：`/data/k3s/storage/pvc-e800dd8a-9d98-41bf-bb61-6a667d4c09b3_office-lab_wopi-data/knowledge-base`。
- 每份文件位于 `<知识库目录>/<32位文件编号>/<原始文件名>`；同名上传分配新编号，不覆盖。旧 `/data/collaboration.docx` 保留，编号仍为 1，也可从列表打开。
- 文件目录为 0700，服务以现有 UID 1000 运行。知识库默认上传容量门限 2 GiB、1000 份文件，可用环境变量 KNOWLEDGE_MAX_BYTES 调整容量。
- 当前沿用共享访问密钥，登录用户共享此知识库，并非按用户隔离的个人空间。

服务器已有文件可以通过项目脚本导入，脚本在有 office-lab kubectl 权限的机器上运行：

```sh
python3 scripts/import-knowledge-file.py /服务器已有目录/文档.docx
```

导入使用与上传相同的文件校验和编号规则。不要把散文件直接放在知识库根目录；不要在文件正在编辑时直接替换磁盘文件。

## 实现与验证

门户提供已认证的 `/api/files` 列表和二进制上传接口；文件名经校验，禁止路径穿越、符号链接和不支持的类型。上传跨站请求被拒绝，前端用 textContent 展示文件名。WOPI 路由使用文件编号，保存与锁按文件分离，采用临时文件后原子替换。

按钮使用 Collabora Insert_Button / Clicked_Button 集成接口。仅为标签栏快捷按钮补充 insertBefore 位置支持，经典工具栏沿用现有能力。样式应用和保存命令不变。

隔离验证覆盖：未登录上传、跨站上传、路径穿越、同名独立编号、WOPI 锁冲突隔离；打开按钮位于保存左侧；知识库打开后编辑并保存且不影响原文档及另一份同名文件；本地上传后自动打开编辑器；服务重启后知识库列表保留。
